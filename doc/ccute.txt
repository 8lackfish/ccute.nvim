1. Introduction                                                  *ccute-intro*

c³ is a color code colorizer with support for HEX, RGB, and HSL (more formats
are planned). It is intentionally small and does not include a color picker.

==============================================================================
2. Setup                                                         *ccute-setup*

Use default config:
>lua
  require('ccute').setup()
<

or with your config (see |ccute-options| for available options):
>lua
  require('ccute').setup({
    -- your options
  })
<

==============================================================================
3. Options                                                     *ccute-options*

`keymaps` (`table`)                                            *ccute-keymaps*

    `apply_line` (`string` | `false`)
        Apply to the current line.
        Default: '<Leader>cc'

    `clear_line` (`string` | `false`)
        Clear from the current line.
        Default: '<Leader>CC'

    `apply_range` (`string` | `false`)
        Apply to a range of lines.
        Default: '<Leader>cr'

    `clear_range` (`string` | `false`)
        Clear from a range of lines.
        Default: '<Leader>CR'

    `string` values use the same key notation as the `{lhs}` of
    |vim.keymap.set()|.
    `false` disables the default mapping.
    Neovim uses `\` as <Leader> by default (see |mapleader|).

`lazy` (`boolean`)                                                *ccute-lazy*
    Lazy mode - Highlights refresh only on file save.
    Default: false

==============================================================================
4. Commands                                                   *ccute-commands*

*:Cute* 	Enable or disable colorizing globally.

		The first execution enables colorizing globally and
		automatically updates highlights while editing, unless
		|ccute-lazy| is enabled.

		Executing the command again disables colorizing globally
		and clears all colorizing.
